# AoE2Wide

AoE2Wide 是一个 Windows 命令行工具，用于为《帝国时代 II：征服者》（The Conquerors）生成宽屏分辨率版本。它会根据可执行文件对应的补丁数据修改游戏分辨率，并生成适配后的界面资源文件和启动批处理文件。

## 使用前准备

- Windows 环境，以及可正常运行的《帝国时代 II：征服者》游戏目录。
- 游戏目录中应有 `language_x1.dll` 和 `Data\interfac.drs`。程序通过前者定位游戏目录，通过后者处理界面资源。
- 从游戏目录或其子目录启动程序，并将适用的 `AoE2Wide*.patch` 文件放在游戏目录树中。`AoE2Wide.exe` 可以放在其他位置，但运行时的当前目录必须位于游戏目录或其子目录中；程序会在游戏目录树中递归查找补丁和游戏可执行文件。
- 补丁按可执行文件的文件大小和 MD5 精确匹配。游戏版本没有对应补丁时，该可执行文件会被跳过。
- 建议先备份游戏目录。原始游戏可执行文件不会被直接改写，但同名的已生成文件会在再次运行时被覆盖。

## 运行

打开命令提示符或 PowerShell，切换到游戏目录（也可以是其子目录），然后运行 `AoE2Wide.exe`。

```powershell
cd "C:\Games\Age of Empires II"
.\AoE2Wide.exe
```

不带参数时，程序会为检测到的每一种显示器分辨率分别生成适配文件。游戏始终使用主显示器，因此多显示器环境下，请确认主显示器设置正确。

也可以指定目标宽度和高度：

```powershell
.\AoE2Wide.exe 1920 1080
```

宽度和高度都必须是整数。程序会查找游戏目录树下所有大于 2 MiB 的 `.exe`，并仅处理能与补丁文件匹配的可执行文件。若指定的尺寸与可用补丁数据不兼容，或游戏资源格式不符合预期，部分修改可能无法完成；请留意控制台中的警告和错误。

## 生成的文件

生成位置在游戏目录中：

- 新的游戏可执行文件：`age2_x1_<版本>_<宽度>x<高度>.exe`
- 启动批处理文件：`AoC<版本> <宽度>x<高度>.bat`
- 适配后的界面资源：`Data\<宽度四位补零><高度四位补零>.drs`；支持相应补丁的版本还会生成 `_x1.drs` 文件
- 桌面上也会创建对应的启动批处理文件，方便直接启动

例如，目标分辨率为 `1920x1080` 时，可能生成 `age2_x1_1.0e_1920x1080.exe`、`AoC1.0e 1920x1080.bat` 和 `Data\19201080.drs`。实际版本标识取决于匹配到的补丁。

建议通过生成的 `.bat` 文件启动游戏。它会以补丁所需的启动参数运行新可执行文件；在部分旧版 Windows 上还可能调用同目录中的 `Process.exe`，暂时挂起并恢复 `explorer.exe` 以处理调色板问题。

## 常见问题

### 找不到游戏目录

请从游戏目录或其子目录运行工具，并确认游戏目录中存在 `language_x1.dll`。从 AoE2Wide 的源码目录直接运行通常无法定位游戏目录。

### 找不到 `interfac.drs`

请确认游戏目录下有 `Data\interfac.drs`，并确认运行时定位到的是正确的游戏安装目录。

### 没有生成适配文件

确认相应的 `AoE2Wide*.patch` 文件位于游戏目录树中，并且补丁对应当前游戏可执行文件。程序要求文件大小与 MD5 同时匹配；不匹配的版本会被跳过。运行窗口中的输出会显示是否找到匹配补丁。

### 提示缺少 `interfac_x1.drs`

这是某些补丁版本需要的扩展界面资源。请确认 `Data\interfac_x1.drs` 存在；若当前游戏版本本来不使用该资源，则应使用对应版本的补丁文件。

### 窗口一闪而过

从命令提示符或 PowerShell 启动可以保留运行输出。直接双击启动时，程序结束前会等待按键；若仍看不到信息，请改用命令行运行。

## 开发与构建

项目位于 `src\AoE2Wide.sln`，目标框架为 .NET Framework 4.8。可使用支持该目标框架的 Visual Studio 打开解决方案并构建。

仓库根目录中的 `AoE2Wide.RootPatch`、`AoE2Wide_*.patch` 等文件是补丁数据，不是普通用户需要手动编辑的配置。

### 高级命令

在游戏目录树中运行以下命令可尝试为 `age2_x1*.exe` 生成补丁文件：

```powershell
.\AoE2Wide.exe createpatches
```

该操作需要 `AoE2Wide.RootPatch`、根补丁对应的原始可执行文件，以及待处理的 `age2_x1*.exe`。生成的 `AoE2Wide_<版本>.patch` 文件会写到对应可执行文件所在目录。这是用于制作或扩展补丁数据的高级功能，日常运行游戏不需要执行。
